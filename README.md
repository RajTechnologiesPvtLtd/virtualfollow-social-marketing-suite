### 🚀 Core Features & Analytics Tools

- **Engagement Rate Calculator & Analytics:** Measure audience interaction and engagement rates across Instagram, YouTube, TikTok, Twitch, and X (Twitter) (`/profiles/{platform}/{username}/analytics`).
- **Influencer Discovery & Directory:** Access a vetted directory of creators for PR and brand collaborations (`/profiles`).
- **Social Media Auditor:** Analyze follower authenticity, active versus inactive accounts, and demographic data through profile insights (`/profiles/{platform}/{username}/analytics`).
- **Planned / Upcoming Tools:** Campaign & brand management utilities (contract generation, brand mention monitoring, and competitor tracking).
